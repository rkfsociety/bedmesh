# Webpanel: карта стола (bed mesh) — design

Дата: 2026-07-19  
Статус: approved for planning  
Область: `webpanel/` (gkbridge + index.html)

## Цель

Показать на веб-панели принтера текущую карту стола (bed mesh) в виде цветной сетки с числами мм — только просмотр, без калибровки.

## Вне скоупа (v1)

- Кнопка `BED_MESH_CALIBRATE` / калибровка
- Выбор и сохранение профилей mesh
- 3D-визуализация
- Чтение mesh из cfg / `printer_mutable.cfg` с диска
- Автоопрос mesh по таймеру

## Layout

1. **Всегда сверху (на всю ширину):**
   - шапка: индикатор связи, «Kobra S1», badge статуса печати;
   - кнопки Пауза / Стоп.
2. **Ниже — три колонки:**
   - **левый вертикальный бар** навигации: **Печать** | **Стол**;
   - **основной контент** (зависит от активного пункта бара);
   - **камера** справа (как сейчас; на узком экране уходит вниз).
3. Вкладка **Печать:** прогресс, температуры, метрики, события (текущее содержимое левой колонки).
4. Вкладка **Стол:** сводка + heatmap mesh + кнопка «Обновить».

Ориентир по виду: макет `webpanel/mockup-mesh-tab.html` (левый бар, не горизонтальные табы внутри карточки).

## Backend: `GET /mesh`

Новый эндпоинт в `gkbridge.go`.

### Запрос к gklib

`objects/query` только с объектом `bed_mesh` (отдельный вызов, не через `/status`).

### Успешный ответ

```json
{
  "ok": true,
  "profile": "default",
  "mesh_min": [5, 5],
  "mesh_max": [245, 245],
  "matrix": [[0.01, -0.02], ["..."]]
}
```

- `matrix` = `probed_matrix` (реальные точки пробы), не интерполированный `mesh_matrix`.
- `profile` = `profile_name`.
- CORS — как у остальных эндпоинтов.

### Ошибки / пустое состояние

| Ситуация | Ответ | UI |
|---|---|---|
| Mesh не загружен (`profile_name` пустой и/или матрица пустая) | `{ "ok": false, "error": "no_mesh" }` | «Карта стола не загружена» + подсказка сделать калибровку в приложении / через Klipper |
| Сокет недоступен / ошибка gklib | `{ "ok": false, "error": "..." }` | «нет связи с принтером» |

`/status` и список `queryObjects` **не** расширяем `bed_mesh`.

## Frontend: загрузка данных

- При **первом** переключении на **Стол** — один `GET /mesh`.
- Дальше mesh **не** опрашивается по таймеру.
- Кнопка **Обновить** в углу блока карты — повторный `GET /mesh`.
- `/status` продолжает поллиться всегда (шапка и кнопки).

## Frontend: отрисовка карты

- Сводка: профиль, min, max, range (мм) по текущей матрице.
- Сетка ячеек: цвет по Z + текст `±0.xxx` в каждой ячейке (как в десктопном `MeshView`).
- Палитра: нормализация min→max **этой** матрицы (soft/classic: синий → зелёный → красный).
- Ориентация: (0,0) принтера слева снизу; для экрана инвертировать Y.
- Кнопка «Обновить» — правый верхний угол блока карты (не мешает сетке).

## Версия и поставка

- Поднять `webpanel/gkbridge.version` → **1.9.0**.
- Пересобрать armv7 бинарник (`build.ps1`), закоммитить `webpanel/gkbridge` как обычно.
- Самообновление панели подхватит релиз с `main` через существующий механизм.

## Проверка

1. `GOOS=linux GOARCH=arm GOARM=7 go build` (или `build.ps1`) без ошибок.
2. UI: левый бар переключает Печать ↔ Стол; шапка и Пауза/Стоп всегда видны.
3. С загруженным mesh: сетка, цифры, сводка; «Обновить» перезапрашивает `/mesh`.
4. Без mesh: empty-state с подсказкой про калибровку.
5. При недоступном сокете: «нет связи с принтером».
6. На вкладке Печать запросов к `/mesh` нет (кроме явного возврата на Стол / кнопки Обновить).

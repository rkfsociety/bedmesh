# Эталонные состояния интерфейса

Эти изображения сняты с собранной Windows-версии BedMesh Visualizer и используются как визуальный референс при дальнейших изменениях интерфейса.

- `01-main.png` — основной экран с картой и анализом меша.
- `02-config-editor.png` — редактор настроек `printer.cfg` с расширенными параметрами Z-homing.
- `03-printer-mutable.png` — экран с необработанными данными `Printer Mutable`.

Скриншоты показывают состояние программы на момент сохранения и не являются тестовыми снимками данных принтера.

# Bed Mesh Visualizer

Инструмент для анализа карты стола 3D-принтера (Klipper/GoKlipper).

## Возможности

- Автоимпорт `printer_mutable.cfg` (JSON и текстовый форматы)
- 2D и 3D визуализация рельефа стола
- Мастер выравнивания: пошаговые инструкции (обороты/мм Z)
- Подключение к принтеру по SSH — без USB
- **Веб-панель на принтере**: статус печати, температуры, управление (пауза/стоп), камера, история событий

## Скачать

Из раздела **Releases**:

- **Windows**: `Bed.Mesh.Visualizer.exe`
- **macOS**: `BedMeshVisualizer_Mac.dmg`
- **Android**: `.apk`

Приложение автоматически проверяет обновления при запуске и предлагает установить их в один клик.

## Запуск из исходников

**Windows** (`win/pyqt6`):
```powershell
py -3 main.py
```

**macOS** (`mac`):
```bash
python3 main.py
```

Зависимости: `win/pyqt6/requirements.txt`

## Ветки и релизы

| Ветка | Назначение |
|-------|------------|
| `main` | общий код, веб-панель (`webpanel/`) |
| `windows` | Windows-специфичный код |
| `mac` | macOS-специфичный код |
| `android` | Android-приложение |

Релизы публикуются по тегу: `vX.YYY-win`, `vX.YYY-mac`, `vX.YYY-android`.  
GitHub Actions собирает артефакт и прикрепляет к релизу автоматически.

## Веб-панель (gkbridge)

Устанавливается на принтер из Windows-приложения (вкладка SSH). После установки доступна по `http://<IP принтера>:8088`.

Самообновляется с GitHub при появлении новой версии — кнопка появляется автоматически в футере панели.

## Вклад в проект (CONTRIBUTING)

### Какие ветки для чего

- **`main`**: общий код/логика/форматы/документация. Считается базовой и стабильной веткой.
- **`windows` / `mac` / `android` / `online`**: платформенные ветки для специфичных изменений (UI, сборка, зависимости, CI).

### Базовое правило

**Если изменение может быть общим — оно должно попасть в `main`.**  
Платформенные ветки должны регулярно подтягивать изменения из `main`.

### Как делать изменения

- **Общее изменение**:
  - ветка задачи от `main` (например `feature/...` или `fix/...`)
  - PR в `main`
- **Платформенное изменение**:
  - ветка задачи от платформенной ветки (например от `mac`)
  - PR в соответствующую платформенную ветку

### Как синхронизировать платформенные ветки с `main`

Рекомендуемый вариант (merge):

```powershell
git checkout mac
git pull
git merge main
git push
```

Альтернатива (rebase, только по договорённости в команде):

```powershell
git checkout mac
git pull
git rebase main
git push --force-with-lease
```

### Релизы

Релизы делаются тегами (см. `readme.md`):

- `vX.YYY-win` — Windows
- `vX.YYY-mac` — macOS

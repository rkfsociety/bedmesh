# Контекст проекта BedMesh

Проектные инструкции и рабочие заметки Codex хранятся в этой папке и должны
оставаться свободными от секретов, токенов и машинных кэшей.

- `memory.md` — индекс долговременного контекста и канонической документации.
- `nozzle-ui-notes.md` — подтверждённые детали Windows-вкладки «Сопло».
- `k3sysui-analysis-2026-08-27.md` — ограниченный исторический вывод анализа штатного UI.

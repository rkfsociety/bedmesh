# Веб-панель Kobra S1 (gkbridge)

Лёгкая веб-панель статуса и управления печатью для Kobra S1 на GoKlipper. Один
бинарник `gkbridge` (Go, без зависимостей) с вшитым `index.html` (`go:embed`).

```
[браузер :8088/]  --HTTP/JSON-->  [принтер: gkbridge :8088]  --unix socket-->  [gklib /tmp/unix_uds1]
```

## Файлы

- `gkbridge.go` — мост: читает Klipper-сокет `/tmp/unix_uds1` (кадры с терминатором `0x03`).
- `index.html` — панель (vanilla JS), вшивается в бинарник при сборке.
- `gkbridge.version` — **версия панели**, вшивается в бинарник и раздаётся через raw GitHub.
- `go.mod`, `build.ps1` — модуль и скрипт сборки.
- `gkbridge` — собранный бинарник (armv7), коммитится: приложение бандлит его, а сама
  панель качает его при самообновлении.

## Эндпоинты

- `GET /` — панель (вшитый HTML)
- `GET /status` — JSON статуса (CORS)
- `POST /control?cmd=pause|resume|cancel` — управление печатью
- `POST /gcode {"script":"..."}` — произвольный gcode (установка температур)
- `GET /version` — версия панели
- `GET /update/check` — сравнение с версией в репозитории (raw)
- `POST /update/apply` — скачать свежий бинарник с GitHub, заменить себя, перезапуститься
- `GET /health` — `ok`

## Сборка

`index.html` и `gkbridge.version` встраиваются через `go:embed`, поэтому собирать из
этой папки:

```powershell
.\build.ps1
```

Скрипт собирает `gkbridge` под armv7. Приложение (PyInstaller) бандлит бинарник прямо
отсюда (`webpanel/gkbridge`).

## Выпуск обновления панели (без новой версии программы)

1. Правишь `gkbridge.go` / `index.html`.
2. Поднимаешь номер в `gkbridge.version` (например `1.0.1`).
3. `.\build.ps1`
4. Коммит + пуш в `main`.

У всех, у кого панель уже установлена, в футере появится кнопка «⬆ Обновить» —
переустановка из программы не нужна.

## Самообновление: TLS

Бинарник качается по HTTPS с **отключённой проверкой сертификата** — на принтере
(busybox) может не быть CA-бандла. URL фиксированный (raw GitHub этого репозитория),
качается собственный бинарник, поэтому риск приемлемый.

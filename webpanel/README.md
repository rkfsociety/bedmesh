# Веб-панель Kobra S1 (gkbridge)

Лёгкая панель статуса и управления печатью для Kobra S1 на GoKlipper.  
Один бинарник `gkbridge` (Go, без внешних зависимостей) с вшитым `index.html` (`go:embed`).

Текущая версия панели: см. `gkbridge.version` (сейчас **1.9.6**).

```
[браузер :8088/]  --HTTP/JSON-->  [принтер: gkbridge :8088]  --unix socket-->  [gklib /tmp/unix_uds1]
```

## Интерфейс

- **Сверху на всю ширину:** индикатор связи, имя принтера, статус печати, кнопки Пауза / Стоп.
- **Слева** вертикальный бар: **Печать** | **Стол**.
- **Справа** блок камеры (на узком экране уходит вниз).

**Печать** — прогресс, температуры, метрики, события.  
**Стол** — сводка по mesh (профиль, min / max / range) и цветная сетка ячеек; данные грузятся при первом открытии вкладки и по кнопке **Обновить** (без автополла `/mesh`).

Если mesh в памяти пуст — подсказка прокалибровать стол; при отсутствии связи — «нет связи с принтером».

## Эндпоинты

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET` | `/` | панель (вшитый HTML) |
| `GET` | `/status` | JSON статуса печати (CORS) |
| `GET` | `/mesh` | текущий `bed_mesh` (`probed_matrix`); если пусто — fallback на `printer_mutable.cfg` / `printer.cfg` |
| `POST` | `/control?cmd=pause\|resume\|cancel` | управление печатью |
| `POST` | `/gcode` | тело `{"script":"..."}` — произвольный gcode |
| `GET` | `/version` | версия панели |
| `GET` | `/update/check` | сравнение с `gkbridge.version` в репозитории |
| `POST` | `/update/apply` | скачать бинарник из соответствующего GitHub Release, заменить себя, перезапуститься |
| `GET` | `/health` | `ok` |

`/status` **не** включает `bed_mesh` — для карты только `/mesh`.

## Файлы

| Файл | Роль |
|------|------|
| `gkbridge.go` | HTTP-мост к Klipper-сокету `/tmp/unix_uds1` (кадры с терминатором `0x03`) |
| `mesh.go` | разбор живого bed_mesh и cfg-файлов для `/mesh` |
| `index.html` | UI (vanilla JS), вшивается в бинарник |
| `gkbridge.version` | версия панели (вшивается и читается клиентами через raw GitHub) |
| `go.mod`, `build.ps1` | модуль и сборка |
| `gkbridge` | собранный бинарник **armv7** (коммитится для локальной сборки и совместимости со старыми клиентами) |

## Сборка

`index.html` и `gkbridge.version` встраиваются через `go:embed` — собирать **из этой папки**:

```powershell
.\build.ps1
```

`build.ps1` использует Go из `PATH`, выполняет `go vet`, затем собирает Linux
`armv7`-бинарник.

Скрипт собирает `gkbridge` под armv7. Desktop (PyInstaller) бандлит бинарник из `webpanel/gkbridge`.

## Выпуск обновления панели

Отдельная версия клиента не нужна. Релиз панели публикуется под тегом
`v<версия>-gkbridge`, например `v1.9.6-gkbridge`:

1. Правки в `gkbridge.go` / `mesh.go` / `index.html`
2. Поднять номер в `gkbridge.version`
3. Из каталога `webpanel` запустить `\.\build.ps1`, чтобы обновить коммитящийся armv7 бинарник
4. Коммит + пуш в `main`; workflow проверит Go, соберёт релизный бинарник и
   опубликует его вместе с SHA-256

Установщики Windows/macOS/Android и кнопка «⬆ Обновить» скачивают бинарник из
соответствующего GitHub Release. Старые установленные панели продолжают
обновляться через сохранённую raw-копию бинарника в `main`.

## Самообновление и TLS

Бинарник качается по HTTPS с **отключённой проверкой сертификата**: на принтере (busybox) часто нет CA-бандла.  
URL фиксированный (raw GitHub этого репозитория), качается собственный бинарник — риск приемлемый для этого сценария.
